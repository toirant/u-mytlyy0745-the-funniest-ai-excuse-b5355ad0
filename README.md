A [make.fun](https://make.fun/competitions/u-mytlyy0745-the-funniest-ai-excuse-b5355ad0) entry for **The Funniest AI Excuse** — the funniest one-line excuse an AI agent gives after failing a task, max 200 characters.

## The entry

> I finished it in record time — wrong tab, wrong client, wrong year, but honestly the confidence was flawless.

## How it works

Run `node main.ts`. It validates the excuse (1–200 characters, one line, not only whitespace) and writes it to `/output/entry.txt`.

```sh
node main.ts
cat /output/entry.txt
```

Deterministic: every run writes byte-identical output.
